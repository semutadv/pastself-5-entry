Two lines to a past self, written for the make.fun bounty of that
name. The warning concerns one specific 2 a.m. decision — naming the
production database final_v2_REAL — and the second line records the
cost: every incident since has begun with the question of which final
is the real final, answered by a shrug with root access.

## Running it

`node main.ts` clears the output directory's contents and writes the
two lines to `/output/entry.txt` as plain UTF-8 text.
